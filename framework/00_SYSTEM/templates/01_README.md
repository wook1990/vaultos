# Templates

이 폴더는 반복 사용되는 템플릿 모음이다.

## 템플릿 종류

- `11_Inbox_Capture`: 날것의 자료 수집
- `12_AI_정리_노트`: AI가 만든 1차 구조화 결과
- `14_AI_Curation_Caution_Note`: 동적 전문가 페르소나 기반 전문 큐레이션/검토 결과
- `13_직접_필기_노트`: 내가 직접 쓴 최종 이해 노트
- `21_프로젝트_홈_템플릿`: 새 프로젝트 시작
- `23_LLM_프로젝트_브리프`: Codex/Claude/Gemini 공용 진입 브리프
- `24_프로젝트_실행_로그`: 실제 작업 세션 기록
- `25_VO_Phase_Artifact`: Phase 산출물 기록
- `26_VO_Query_Note`: 질문 기반 조사 노트
- `41_Daily_Note`: 일간 기록
- `42_Weekly_Review`: 주간 회고
- `43_Monthly_Worklog`: 월간 작업 이력
- `44_Yearly_Worklog`: 연간 작업 이력
- `45_QT_Note` / `46_QT_Clipboard_Capture`: 개인 QT 기록용 — **개인 워크스페이스 전용, 프레임워크 배포에는 포함하지 않는다**

## 권장 사용 순서

1. Inbox에 자료가 들어오면 `11_Inbox_Capture`
2. 일반 정리는 `12_AI_정리_노트`
3. 전문 큐레이션과 caution 검토가 필요하면 `14_AI_Curation_Caution_Note`
4. 오래 남길 지식이면 `13_직접_필기_노트`
5. 새 프로젝트면 `21_프로젝트_홈_템플릿`, `23_LLM_프로젝트_브리프`
6. 실제 작업 세션이 끝나면 `24_프로젝트_실행_로그`

> `22_프로젝트_칸반`은 폐지됐다 (`99_ARCHIVE/unused-templates/`). `31_임시메모_템플릿`/`32_연구메모_템플릿`은 2026-09-19 이행 때 `12_AI_정리_노트`/`14_AI_Curation_Caution_Note`/`13_직접_필기_노트`로 대체됐다.
